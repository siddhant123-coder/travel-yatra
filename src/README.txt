TRAVEL YATRA — REACT ROUTER STRUCTURE

1. Run: npm install react-router-dom
2. Copy the components/ and pages/ folders into src/.
3. Replace src/App.jsx and src/main.jsx with the supplied files.
4. Keep your existing src/design.css unchanged.

Routes:
 /             Full landing page
 /destinations Destinations section
 /packages     Packages section
 /custom-trip  Custom trip section
 /itinerary    Itinerary section
 /bookings     Bookings section
